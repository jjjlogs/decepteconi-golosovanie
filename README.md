# DECEPTICON AWARDS — статичная версия (GitHub Pages + Google Таблица)

Это полностью фронтенд-версия сайта: никакого Node.js-сервера, всё голосование
можно захостить на GitHub Pages, а результаты будут прилетать прямо в Google Таблицу.

## Что изменилось по сравнению с версией на Node.js

- Номинации теперь зашиты в `js/nominees-data.js` (раньше отдавались сервером через `/api/categories`).
- «Уже проголосовал» хранится в `localStorage` браузера, а не в файле на сервере.
  Это значит: если человек проголосует с телефона и с компьютера — это будут
  два разных голоса (сервер такого не мог отследить и раньше в 100% случаев,
  но локально ограничение снимается легче, например через приватный режим браузера).
- Каждый голос сразу же отправляется в Google Таблицу через Google Apps Script.
- Счётчики голосов на сайте по-прежнему никому не показываются — они видны только
  в самой таблице.

## Шаг 1. Создай Google Таблицу и скрипт

1. Зайди на [sheets.google.com](https://sheets.google.com) и создай новую пустую таблицу.
   Назови её, например, «Decepticon Awards — голоса».
2. В меню сверху: **Расширения → Apps Script**.
3. Откроется редактор скрипта. Удали весь код-заглушку и вставь содержимое
   файла `google-apps-script.gs` из этого архива.
4. Сохрани проект (иконка дискеты или Ctrl+S). Название проекта можно оставить любое.
5. Нажми **Deploy → New deployment** (Развернуть → Новое развёртывание).
6. Рядом с «Select type» нажми на шестерёнку и выбери **Web app**.
7. Настрой:
   - **Execute as**: Me (твой аккаунт)
   - **Who has access**: Anyone (важно — иначе сайт не сможет писать в таблицу)
8. Нажми **Deploy**. Google попросит разрешить доступ — подтверди (это твой
   собственный скрипт, предупреждение про «непроверенное приложение» нормально,
   нажми «Advanced» → «Go to ... (unsafe)» → «Allow»).
9. Скопируй **Web app URL** — он выглядит примерно так:
   `https://script.google.com/macros/s/AKfycb.../exec`

## Шаг 2. Вставь URL в сайт

Открой `js/app.js`, в самом начале файла найди строку:

```js
const GOOGLE_SCRIPT_URL = 'ВСТАВЬ_СЮДА_URL_СКРИПТА';
```

Замени `'ВСТАВЬ_СЮДА_URL_СКРИПТА'` на скопированный URL, например:

```js
const GOOGLE_SCRIPT_URL = 'https://script.google.com/macros/s/AKfycb.../exec';
```

Сохрани файл.

## Шаг 3. Залей на GitHub Pages

1. Создай новый репозиторий на GitHub (или используй уже существующий).
2. Помести содержимое этой папки (`index.html`, `css/`, `js/`, `img/`) в **корень**
   репозитория (или в папку `docs/` — как удобнее).
3. Закоммить и запушь:
   ```bash
   git add .
   git commit -m "Static version with Google Sheets voting"
   git push
   ```
4. В репозитории: **Settings → Pages**.
5. В **Source** выбери ветку (обычно `main`) и папку (`/root` или `/docs` —
   в зависимости от того, куда положил файлы).
6. Сохрани. Через минуту-две сайт будет доступен на
   `https://<твой-юзернейм>.github.io/<репозиторий>/`.

## Проверка

Открой сайт, проголосуй в любой номинации, затем открой Google Таблицу —
в листе **Votes** должна появиться новая строка с твоим голосом.

## Ограничения такого подхода (важно понимать)

- Любой человек, открыв код страницы, может увидеть URL Google-скрипта и
  теоретически отправить в таблицу «мусорные» голоса напрямую (в обход сайта).
  Для фан-голосования среди своих это обычно не проблема, но если важна
  защита от накрутки — такой подход не подходит.
- Ограничение «один голос» держится только в браузере пользователя
  (localStorage). Очистка данных браузера или голосование в режиме инкогнито
  снимает это ограничение.
- Итоговый подсчёт (кто победил) удобнее всего смотреть в самой Google Таблице —
  например, через сводную таблицу (Pivot table) по столбцам «Категория» и «Ответ».
