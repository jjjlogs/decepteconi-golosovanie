# DECEPTICON AWARDS 🤖

Сайт голосования: номинации, варианты ответа + возможность вписать свой,
один голос на категорию с человека (запоминается через cookie),
голос можно отменить и проголосовать заново. Результаты никому не
показываются — ни в процентах, ни в виде лидера.

## Запуск

Внешних пакетов нет, `npm install` не требуется — только Node.js.

```bash
node server.js
```

Открой в браузере: **http://localhost:3000**

Порт можно поменять переменной окружения `PORT`:

```bash
PORT=8080 node server.js
```

## Как редактировать номинации

Открой `data/nominees.json` — это массив категорий:

```json
{
  "id": "deceptiking",
  "title": "Deceptiking",
  "subtitle": "",
  "options": [
    { "id": "shaitan", "label": "Шайтан", "votes": 0 }
  ],
  "allowCustom": true
}
```

- `options` — фиксированные варианты ответа.
- `allowCustom: true` добавляет в конце карточку «Свой вариант» с полем
  для ввода текста.
- Добавляй/убирай категории и варианты как угодно, сервер подхватит
  изменения при перезапуске.

## Как считаются голоса

- При первом заходе браузеру выдаётся cookie `voter_id`.
- `data/voters.json` хранит, кто за что проголосовал в каждой категории.
- Повторный голос в той же номинации сервер отклоняет (`409 Conflict`) —
  сначала нужно отменить текущий голос.
- **Отмена голоса**: кнопка «Отменить выбор» в карточке категории —
  снимает голос и разблокирует все варианты для повторного выбора.
- **Свой вариант**: если у категории `allowCustom: true`, пользователь
  может вписать текст вместо выбора из списка. Все такие ответы
  складываются в `data/custom-entries.json` (текст + время).
- **Результаты скрыты от пользователей** — публичный API
  (`/api/categories`) отдаёт только список вариантов, без счётчиков
  голосов. Счётчики для фиксированных вариантов копятся внутри
  `data/nominees.json` (поле `votes`), но по сети наружу не уходят —
  посмотреть их можно, только открыв файл на сервере напрямую.
- Это защита «на честном слове» — для публичного голосования с высокими
  ставками стоит добавить авторизацию и защиту от накрутки (rate
  limiting, капчу и т.п.).

## Как посмотреть итоги (для организатора)

Открой на сервере:
- `data/nominees.json` — счётчики голосов за фиксированные варианты
  (поле `votes` у каждого варианта).
- `data/custom-entries.json` — все вписанные вручную варианты по
  категориям.

## Деплой

Обычное Node.js-приложение — подойдёт любой хостинг с поддержкой Node
(VPS + pm2, Render, Railway и т.д.). Скопируй папку на сервер и
запусти `node server.js`; не забудь открыть нужный порт.
